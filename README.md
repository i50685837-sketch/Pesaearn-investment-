# 💰 Pesaearn Investment

A modern investment and survey reward web application built with HTML, CSS, JavaScript and backend support.

## 🚀 Features

### 👤 User Account
- User registration
- User login
- Profile management
- Profile picture upload
- Change name and email
- Password update
- Theme settings

### 📊 Dashboard
- User overview
- Investment balance
- Reward points
- Quick navigation menu
- Hamburger menu

### 💰 Investment System
- Minimum investment: KSh 650
- Investment duration:
  - 3 hours
  - 12 hours
  - 24 hours
  - 48 hours
  - 72 hours
- Investment tracking

### 📋 Survey System
- Multiple surveys
- 10-question survey format
- Earn reward points after completion
- Points increase account balance

### 🎁 Rewards
- Reward points tracking
- Redeem rewards
- Reward history

### 👥 Referral System
- Referral code generation
- Invite friends
- Referral tracking

### 👛 Wallet
- Balance display
- Investment records
- Transaction history

### 🔔 Notifications
- Account updates
- Investment notifications
- Survey rewards

### 🆘 Support
- Contact support
- FAQ section
- Send support requests


## 🛠️ Technologies Used

Frontend:
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

Backend (planned/connected):
- Node.js
- Express.js
- MongoDB
- JWT Authentication
